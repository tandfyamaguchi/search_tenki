# 「天気」記事検索 — 管理・日常運用

この文書は、本番環境でDjango adminを使う運用担当者向けです。環境構築、初期管理者の作成は [README_ini.md](README_ini.md) を参照してください。

以下の `python manage.py` コマンドは、Minicondaの `search-tenki-dj52` 環境を `conda activate search-tenki-dj52` で有効化してから実行します。

## 1. 管理画面の基本

管理画面の入口は `/admin/` です。初回導入時に `createsuperuser` で作成した利用者は全権限を持ちます。

記事の日常操作は、ホームにある案内どおり「発行管理」→「巻」→対象の「号」から始めます。号の行で「この号に記事を追加」または「この号の記事を編集」を選びます。

パスワードを忘れた場合

```sh
cd ./search_tenki
conda activate search-tenki-dj52
python manage.py changepassword '<運用担当者の個別ID>'
```

## 2. adminで操作できる範囲

現在の実装でadminに登録されているデータは次のとおりです。

|admin上の対象|主な内容|公開画面への影響|運用上の注意|
|---|---|---|---|
|`記事`|題名、巻、号、開始頁、PDF、カテゴリ、内容分類、著者、キーワード|検索結果と記事表示|通常は「発行管理」→「巻」→「号」から追加・編集する。|
|`カテゴリ`|カテゴリ名、原稿種別、使用中の記事数|詳細検索のカテゴリ表示、記事のカテゴリ|原稿種別を必ず指定して追加・変更する。使用中のカテゴリは削除できない|
|`内容分類`|内容分類名、使用中の記事数|詳細検索、記事の内容分類|追加・変更できる。使用中の内容分類は削除できない|
|`キーワード`|キーワード名、使用中の記事数|検索結果、記事のキーワード|追加・変更できる。使用中のキーワードは削除できない|
|`原稿種別`|原稿種別名、表示順、カテゴリ数|詳細検索のカテゴリの並び|追加・変更できる。カテゴリを含む原稿種別は削除できない|
|`著者`|著者名、使用中の記事数|記事の著者表示|未使用の著者名だけを削除できる。表記の変更はしない|
|`Year`（巻）|発行年、巻番号、所属する号|巻の選択画面|「発行管理」内の「巻」から追加する。既存の巻では号・記事を管理する|
|`Month`（号）|号番号、開始頁|号の選択画面、巻号検索|単独メニューには表示されない。対象の巻を開いて追加・変更する|
|標準の「ユーザー」「グループ」|管理者のアカウントと権限|adminの利用可否|最小権限と個別アカウントを守る|

カテゴリ、内容分類、キーワード、原稿種別は「記事管理」に表示されます。カテゴリを追加・変更するときは、必ず所属する原稿種別を選びます。

カテゴリ・内容分類・キーワード・原稿種別の名称や表示順の変更は、既存記事と公開検索にも反映されます。公開画面を確認してから完了してください。使用中かどうかは一覧の件数で確認できます。未使用のものだけが削除できます。

## 3. 巻・号（Year / Month）の管理

adminの「発行管理」内にある「巻」です。巻一覧には巻番号、発行年、登録号数、登録済みの号が表示されます。対象の巻を開くと、見出しに「第66巻（2019年）｜登録号: 1〜9」のような要約と、その巻の号だけを表形式で表示します。表には号番号、号の開始頁、記事数、操作が並びます。`Month`（号）は単独メニューに表示されません。

既存の巻を開いた画面では、巻番号・発行年の入力欄や保存ボタンは表示しません。巻を識別する情報は変更せず、この画面で号と記事を管理します。

### 巻と号を追加・編集する場合

1. 新しい巻が必要な場合だけ「巻を追加」から巻番号と発行年を入力して保存する。
2. 対象の巻を開き、「号を追加」から号番号と開始頁を入力する。保存後は発行管理の表へ戻る。
3. 通常号・特別号を問わず、必要な号は「号を追加」から1件ずつ登録する。開始頁は自動推測しない。
4. 表の登録号・開始頁・記事数を確認する。「この号に記事を追加」は掲載先を指定済みの記事追加画面を開く。
5. 既存記事を扱う場合は「この号の記事を編集」を選ぶ。対象の巻・号で絞り込まれた記事一覧が開くので、記事の題名を選んで編集する。
6. 公開画面で対象巻を開き、号が番号順に表示されることを確認する。

既存記事がある巻番号・号番号は変更・削除できません。

## 4. 記事（Kijis）の管理

記事の追加・変更・削除は、通常は「発行管理」→「巻」→「号」から追加・編集します。「記事管理」→「記事」からも追加・編集できます。

### 記事を追加する場合

1. 先に「発行管理」の「巻」で、掲載先の巻と号を登録する。通常は対象号の行にある「この号に記事を追加」から開くため、巻・号は最初から選択されている。「記事管理」の「記事」から直接追加することもできる。
2. 題名、巻、号、記事の開始頁を入力する。巻を選ぶと、その巻に登録済みの号だけが候補に表示される。
3. カテゴリ、内容分類、キーワードは、先に「記事管理」の各マスタで管理してから選択する。記事画面でも文字を入れて既存候補を検索できる。
4. 「著者（公開表示順）」の表で、公開する順に著者と「表示順」を入力する。筆頭著者を1、次を2のように指定する。同じ著者・同じ表示順は登録できない。
5. 追加・変更画面を保存せず「入力を破棄して元の画面に戻る」を選んだ場合、記事の作成・変更は行われない。発行管理から追加した記事は親の巻へ戻る。ただし、記事追加前に別画面で作成したマスタや著者名は残るため、不要なら使用中の記事数が0であることを確認して削除する。
6. PDFの相対パスを入力する。この画面はPDFのアップロード機能ではない。

新規導入時の原稿種別25件とカテゴリID 1〜206の対応は、`basemodel/initial_data/` のCSVを正本として管理します。空の検索用DBへスキーマを作成した後、`initialize_search_db` がCSVから原稿種別とカテゴリを投入します。初期同期後の原稿種別・カテゴリの管理は、Django adminで行います。

## 5. カテゴリと原稿種別の管理

詳細検索画面のカテゴリ表示は、運用DBに保存した次の情報で決まります。

- `CategoryGroup`: 原稿種別の名称と表示順
- `Category.group`: 各カテゴリが所属する原稿種別
- `Category.name`: カテゴリの正式名称

カテゴリを追加・変更したときは、次の順で操作します。
1. 「記事管理」→「原稿種別」で名称と表示順を登録・確認する。
2. 「記事管理」→「カテゴリ」で所属する原稿種別を指定する。
3. 詳細検索画面で表示順と名称を確認する。

## 6. 定期確認

少なくともリリース前、カテゴリ・原稿種別を変更した後には、次を確認します。

```sh
python manage.py check
python manage.py check --deploy
```

```sh
python manage.py test
```
